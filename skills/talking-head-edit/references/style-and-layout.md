# 风格选择与构图编排

## 风格选择是项目参数，不是固定皮肤

先问一个问题：“这条片想呈现什么气质？可以给参考，也可以让我展示几种样式。”根据内容给2–3个有区别的选项，用户也可自定义。例如成熟编辑排版、纸艺拼贴、轻趣味2.5D、克制科技风；这些是可选方向，不是全部影片必选菜单。

给视觉样式时用同一段口播、同一人物帧和相同信息作比较，标明是静帧提案还是已实现动效。不以颜色变化充当两种不同风格；比较字体尺度、材质、空间、构图和动作语言。栅格概念图生成使用可用图像工具；精确版式可用代码渲染。本人身份用原片，不擅自生成替身。

将确认结果保存为项目 `style.json` 或 `edit-plan.md` 风格节，至少包含：

- 配色：底色、正文、强调、问题提示；对比度与原片光线兼容。
- 字体：字重、层级、字幕行数和中英处理；按本次要求或[已确认字幕偏好](motion-calibration.md#人像与双语字幕)安排语言与层级。
- 材质：纸张/平面/金属/黏土等及允许的组合。
- 动作：速度、曲线、弹性、停留、转场原则。
- 人像：主体或陪伴角色、窗口形状、允许的布局变化。
- 外部动画：成熟度、角色比例、场景语言，与文字动效同一视觉体系。
- 来源：用户选定/参考提炼/暂定；确认时间与明确不喜欢的特征。

参考视频用于拆解构图、信息出现过程、景别和停留，不复制其品牌、人物或每个装饰。无法读取链接时请用户上传或提供关键片段，不声称已经观看。账户已有样式可续用；用户说换风格时更新本项目参数，不拖回旧模板。

## 有效画面与文字安全区

识别原片有效内容矩形。默认所有标题、字幕、英文、占位说明都在有效画面内，上下/左右黑边保持无字；实际坐标由原片决定，不能套用某条视频的120–840。去黑边或重裁切需符合用户要求，不能靠丢脸、丢手势换取空间。

解释区域避开脸、眼镜和关键手势。留白不足时缩小/偏置人物或切全屏解释；不要堆字挡脸。镜头移动中也要检查文字安全和标题交叠。

## 人物不是固定角落的贴图

在分镜中轮换有语义理由的布局：

| 讲述任务 | 构图候选 |
|---|---|
| 建立观点、亲身体验、结尾 | 真人大画面/近景，少量强调 |
| 简单重点、四项效果演示 | 真人大画面，效果直接作用于画面 |
| 需要同时看人和解释 | 真人偏置，旁侧解释区；左右由视线及空间决定 |
| 复杂关系、操作界面 | 解释或录屏主导，同步小窗或暂不显示人像 |
| 进入/退出解释 | 同一人物连续缩放、位移，解释层跟随展开/收起 |

检查每个长段和全片布局分布。若所有露脸段都锁在同一矩形位置，重新按语义安排，而不是机械每秒换角落。风格一致不等于版式固定。

连续转场保留同一时间的人像和原声：大画面缩小并位移 → 到位前后解释层进入 → 停留阅读 → 解释层收回 → 真人放大回来。过渡约0.4–0.8秒可作起点，按语速调整；既不强制此时长，也不每句话都动。转场中让旧标题先退出，新说明到位后进入，避免两层半透明标题叠在脸上。

组合使用直接切近景、连续缩放位移、窗口匹配、少量蒙版揭示。保持重点镜头干脆；没有语义用途的飞旋或全屏闪光不作为默认装饰。不要镜像人物以迁就布局，也不要用其他时刻的正脸替代正在侧头的同步人像。

## 解释动作要有过程

使用“起始状态 → 变化 → 结果 → 阅读停留”，不是仅写名词。例如：

- 自动剪辑：不同素材轨从错位到对齐，播放头推进，再出现完整预览；注明概念示意。
- 四层包装：关键词运动、局部光效、音轨、字幕分别响应说到的词，不是四个相同色块。
- 提修改：先定位被审核视频的时间范围，再指出问题，再展示修改要求；真实结果缺失则留位。
- 抽象概念：在统一风格下选有趣的短场景隐喻，再回到口播解释；不要求每个概念都做生成动画。

上述是动作结构示例，不能跨主题照搬剪辑时间线。风格可用几期再复盘，但数据受内容、受众等多因素影响，单条数据不能证明某种颜色或动画必然有效。
