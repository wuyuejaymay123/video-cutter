# 外部动画与录屏协作

## 能力分工

先检查实际可用工具。Remotion适合确定性动效和合成，不意味着它技术上不能做复杂3D；按成本、可控性和效果选择工具。复杂物理交互、叙事角色和写实镜头可交给生成视频或3D软件，不能接入时直接交付用户可执行任务。

推荐具体模型/软件前核实当前官方能力、输入方式、时长和用户可用入口。不要把某个Seedance版本、付费套餐或账号权限写成永恒前提。不为一次项目要求用户安装所有技能；只在确有缺口时说明工具用途、替代方案和是否涉及付费/上传。第三方上传或花费额度需符合用户授权。

## 每个外部素材任务必须独立可执行

保存为 `asset-tasks.md`，编号用于分镜、占位和回填。每项包含：

1. 编号、对应原片时间、口播原句、解释目的、选此表现方式的原因。
2. 类型与推荐工具：录屏/图片/生成视频/3D；谁制作，现有/缺失/用户生成中/已返回/已接入。
3. 使用时长、建议生成/录制时长、前后余量，画幅、最低可用分辨率、可接受帧率。参数由本片决定，不强制所有动画3秒。
4. 共同风格参考及其作用：风格参考、首帧或末帧，不混用。A/B关联镜头尽量共享场景、材质、镜头高度与光线。
5. 可复制完整提示词：主体、环境、材质、构图、动作顺序、镜头运动、结束状态、人物小窗和字幕留白。给出避免项，如错误风格、生成文字、品牌标志、复杂手指交互。
6. 分段节拍与后期进入/退出方式；提示词节拍是目标，不保证模型帧级执行。精确文字、字幕、数字和UI留给后期。
7. 导出格式、文件名与验收标准；失败时可简化的动作或备选工具。

提示词结构示例（填写本项目内容后才交付）：

“一段[时长/画幅]镜头，沿用参考图的[材质、颜色、空间、光线]。[构图及保留区]。开始[状态]；随后[单一主要动作]；最后[可读结果并停留]。[镜头运动或固定镜头]。不生成字幕、标志或界面文字；[风格与动作避免项]。”

如果用户只能上传首帧，首帧必须适配镜头的起始状态；风格图内容不匹配时先制作正确首帧，不能把“机械臂工作中”的图硬当“手工忙碌”的首帧。

## 录屏任务

写清：打开哪个界面、起止状态、要展示的真实动作、需要看清的文字区域、停留时间、不要录入的私人信息。拍摄/录屏文字不要冒充用户真实操作。检查已有素材是否与本次请求对应；用户要求录屏留空时，即使存在旧录屏也不接入。

录屏不会凭空提供工具当前支持的功能：示意界面、提炼文案、实际UI分清标注。安装输入不等于安装成功；发布流程不等于已发布。

## 占位预览

用户说“能做的先做”时执行，不因缺外部素材停住整个制作：保留该段口播和时长，空出约定区域，写“待补动画/录屏 + 编号 + 内容 + 使用时长”，必要时保留同步人像。占位文字同样在有效画面内。用户也要求录屏留空时全片一致执行。

占位不能用卡片动画或生成静帧冒充已完成素材。画面仅显示当前观看有用的说明，详细提示词放任务单；正式成片移除占位编号、进度和制作备注。

## 收到素材后

核对编号、尺寸、方向、时长、帧率、主体动作、风格、留白、隐私及水印。用户导出版本可用性不确定时说明，不能裁水印来伪装授权。素材默认静音，保持口播连续；需要保留素材音轨时再混音。按实际动作重新选入出点，文字、人物、转场与音效在后期统一，不硬拉伸重要动作来凑时间。

只有已验证素材真正接入时间线，才标记为“已接入”。无法满足镜头目的时说明差异并给具体重做要求，不盲目塞入。
