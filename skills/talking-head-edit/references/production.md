# 实施、续作与交付

## 快速开始而不是硬套模板

复用现有Remotion工程、依赖、转写和经核实的素材。读取真实版本、脚本、浏览器与FFmpeg路径，不把某台机器的绝对路径、固定帧率或包版本带入技能。保留原文件和用户改动，新增组合/版本；安装依赖前先确认确实缺失。

转写工具不可用时检查可用本地/授权转写途径，仍无法取得准确口播则请用户提供字幕或文本，不编造时间码。不默认上传原视频给第三方。

在项目的 `edit-plan.md` 中保存当前阶段及续作入口：

- 原片、转写来源、内容矩形、画幅、目标规格；
- 风格选择与确认状态；
- 每段镜头及外部素材ID；
- 工程目录、组合名、最新预览、验证结果；
- 已完成、待补素材、用户最后意见、下一步。

长项目可另存机器可读 `timeline.json`，字段对应源起止、输出起止、布局、关键帧、字幕、音轨与素材状态。不要仅把时间写在聊天里导致继续时重新分析。

## 制作边界

- 口播原声是一条连续时间基准；场景切换不能重置人像/音频播放。字幕、角落小窗与对应源时间一致。
- 缩放位移使用帧驱动关键帧和缓动；解释层的显隐与人物让出的空间配合。宽高比变化若需要裁切，检查侧头和手势。
- 按当前有效区域定义字幕安全边界，外层裁切防止文字落入黑框；不能用裁切掩盖被截断的文本。检查字幕长度、换行和手机尺寸可读性。
- 真实UI用裁切、放大、局部蒙版、指示线，不重绘虚假结果。示意音轨/时间线标清，不伪装为真实数据。
- 准确文本由Remotion绘制，外部生成视频提供视觉内容。
- 如需声音，按动作选择少量轻点击、落点或滑动音；口播优先，背景音乐、连续音效不是默认必需。使用可授权来源并控制混音，预览没加音效就明确说明。

## 预览与修改循环

用户先要文字就交文字；用户说开始做就实现，不用新计划替代文件。对于全新风格或全局布局重做，短样片覆盖关键变化后让用户判断；已有验收方向且要求完成剩下的，直接做全片。

540p/720p是可选低清规格，不是固定成片尺寸。时长尽量覆盖完整口播，用户指定短样片时说明范围。对占位的批准只表示流程和节奏获准，不表示外部素材已验收。

渲染中断先检查任务进程与输出，防止重复渲染；有MP4文件不代表完成。使用本地可用浏览器可避免不必要的下载；具体参数以当前CLI为准。

局部重渲染再回填时，明确全局帧范围、片段局部时间与帧率；保持原声，核对边界帧和全片总时长。不可用粗糙拼接造成音频跳变。保留可从原始素材重建的源码，正式版不能仅放大低清预览。

## 验收清单

1. **技术**：修改文件的类型/语法检查通过；输出尺寸、帧率、时长、音轨符合本次要求；整片可解码，开头结尾有效。
2. **空间**：抽查每类布局及转换中间帧，字幕、标题、说明都在有效区域；脸与关键手势未被裁断或遮挡；深浅背景文字都清楚。
3. **变化**：露脸、解释、演示、收尾有按语义安排的景别/主次变化；不是全程相同人物位置，也不是为变而变。
4. **时间**：动态检查大变小和位移，标题错开、解释到位、停留可读；代表性片段检查原声与人像/字幕同步。静帧不能证明运动顺畅或音画同步。
5. **真实性**：源片与转写匹配，素材编号正确；模拟图形标示意，缺素材标待补，不用旧项目结果混充。
6. **声音**：检查口播可懂、无重复音轨/明显断裂，音乐或音效不会压住口播；没听审的部分如实说明。
7. **交付**：实际文件链接、完成范围、尚待补齐项、建议查看的时间点。更新项目状态，保留旧版。

用户明确要求正式片且素材齐备时，从原片和原始素材按确认的参数重渲染，移除占位与工作说明。只有预览可用或尚有缺口时，不宣称“最终完成”。
