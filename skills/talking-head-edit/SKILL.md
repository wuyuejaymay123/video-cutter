# 自选风格口播剪辑

把已经拍好的口播变成“看本人表达 → 看解释 → 看演示 → 回到本人”的视频。依据语义安排图形、镜头、字幕和声音，不用同一个版式逐句换标题。默认 Remotion 做可控动效与合成，复杂场景动画使用适合的外部工具；用户当前要求优先。

## 从本次阶段开始

先检查本项目已有源片、转写、风格确认、分镜、素材状态与最新预览。延续已确认选择，不覆盖其他版本。

| 用户意图 | 本次交付 |
|---|---|
| 上传视频、看看、讨论怎么剪 | 核对内容，提出风格选择或带时间码的方案；不是自动发布或付费生成的授权 |
| 开始做、快速剪一版 | 确定或沿用风格后，实际制作可播放预览，不止给计划 |
| 能做的先做，其他空出来 | 制作可完成部分，外部素材原位留空，保留原声、时长与必要同步人像 |
| 修改布局/动效 | 针对指出的问题实现并导出新版本；全局构图方向未确定时可先做短样片 |
| 继续完成剩下的 | 沿用已确认样片完成全长，不重新选择风格 |
| 素材做好了/最终合成 | 对齐素材、替换占位，检查再交付对应预览或正式版 |

仅规划时遵守规划边界；需要渲染的请求以实际文件为完成条件。缺少风格这类关键选择时一次问一个问题。工具执行受阻时完成可独立的工作并明确缺口。

## 1. 建立可靠时间线

- 探测时长、分辨率、帧率、旋转、音轨、实际内容区域和黑边；画幅沿用原片或本次要求，不强制竖屏。
- 查看不同时间点的人物位置、表情、侧头和手势；听取/转写口播，术语和人名重点校对。旧转写先核对对应音轨及长度，不凭相似文件名复用。
- 保留原声与语义顺序；脚本已确定时，专注画面包装。删停顿或重排内容需要本次请求允许。
- 在项目中维护 `edit-plan.md`：来源、实际内容区域、风格、逐段方案、素材编号/状态、下一步。素材源入出点与原片时间分开记录；变速或删减需记录输出映射。

完成条件：方案能逐段对应真实口播，未知信息标明，未把旧项目的内容当新片证据。

## 2. 选择风格，再设计画面

读 [风格与布局](references/style-and-layout.md)。用户选择决定颜色、材质、字体、动画语言，不锁定历史的绿色、钴蓝、剪纸或写实CGI。没有参考视频也能建立风格。

新片风格未明确时先确认；“动效自行发挥”不代表已选择历史配色。已有本项目确认或明确授权选择整体风格时直接继续。风格只作用于本项目或用户指定系列。

首次设计，以及修改风格、动效丰富度、字幕或开头情绪时，读[风格与动效校准](references/motion-calibration.md)：同内容风格提案→动态样片；以景别变化、分层过程、操作反馈和语义转场检查动效丰富度；逐字冲击与疑问情绪；全屏约束、上下双语字幕、生成图片分层合成和局部修改交付。

## 3. 逐段分镜与制作分工

为每个语义段记录：`原片起止 | 口播要点 | 观众需要理解什么 | 布局与人物位置 | 视觉动作及理由 | 进出方式与停留 | 字幕/声音 | 工具与素材编号`。

- 精确文本、图表、时间线、局部放大、蒙版、字幕、人物连续缩放位移、合成：Remotion。
- 真实操作与结果：用户录屏/截图；不伪造界面、安装成功或发布结果。
- 有场景、物体交互、角色动作、材质或镜头运动的复杂叙事：评估外部视频/3D工具，不用几张卡片充当已完成的复杂动画。
- 每句话分析核心信息，但不要求每句换场景。允许静止、露脸和阅读留白；信息复杂度决定画面密度。

复杂动画或素材缺失时，读 [外部素材协作](references/external-assets.md)。所有当前未能接入的素材都有明确状态和下一步，不假装完成。

## 4. 实际制作与预览

读 [制作与验收](references/production.md)。如环境中可用，读取 `remotion-best-practices` 的入口及本次所需参考；不可用时检查现有项目/官方文档，不要求用户安装整个工具集合。

默认先出文字方案供确认，再低清预览；用户明确要求直接做、先做能做的或继续现有版本时，不重复设置确认关卡。新视觉方向可先做覆盖“露脸、解释、素材切换”的短样片，验收后扩至全长。

## 完成条件

- 方案交付：准确时间码、可执行分工和完整素材任务。
- 预览交付：真实可播放文件、当前完成范围、占位说明；检查画面、参数与解码。
- 正式交付：用户要求范围内的素材全部替换，移除占位与工作说明，从原始素材渲染并验证。缺素材时只称为预览/部分完成。

报告时提供可点击路径与值得看的时间点。只陈述已验证内容；不承诺播放、点赞、收藏或涨粉结果。不自行发布视频、购买生成额度或上传私人素材至第三方。
